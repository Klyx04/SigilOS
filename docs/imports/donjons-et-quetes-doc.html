Donjons, Quêtes & Sorties de Guilde

Le module Donjons, Quêtes & Défis centralise l'organisation de toutes les activités de groupe de votre guilde. Il permet à chaque membre de proposer une sortie, de définir des objectifs précis (succès spécifiques, quêtes d'alignement, Dofus, Songes Infinis), de composer une équipe équilibrée et de synchroniser instantanément l'événement avec votre serveur Discord.

Synchronisation Discord bidirectionnelle

Dès qu'une sortie est créée, un message interactif complet est généré dans le salon Discord configuré par vos officiers. Les membres peuvent postuler ou se désister directement depuis Discord via des boutons dédiés, sans quitter leur application.

🏰 Donjons

Organisez le passage de n'importe quel gardien de donjon, avec sélection des succès visés (Spécial, Hardi, Premier, Duo...), fiches tactiques et mode multi-donjons.

📜 Quêtes

Rassemblez des compagnons pour les combats de quêtes épiques (Dofus Ocre, Ivoire, Ébène, Pourpre...), les quêtes d'alignement ou les chasses aux avis de recherche.

⚡ Défis & Songes

Planifiez des runs personnalisées de Songes Infinis, des sessions de farm de ressources rares ou des sorties d'entraînement de guilde.

1. Créer une nouvelle sortie

Pour créer une sortie, cliquez sur le bouton + Nouvelle Sortie en haut de la page. Le formulaire vous permet de paramétrer précisément votre session :

  • Mode de la sortie : Choisissez entre Donjon, Quête ou Défis.
  • Cible & Niveau : Sélectionnez le donjon dans la liste déroulante (recherche par nom de boss ou de donjon). Le niveau recommandé est calculé automatiquement.
  • Succès visés (Optionnel) : Cochez les challenges que vous souhaitez réaliser (ex. Premier, Statue, Spécial). Ils apparaîtront sous forme d'icônes officielles sur votre carte et sur le message Discord.
  • Nombre de places : Définissez la taille maximale du groupe (de 2 à 8 places).
  • Date et heure : Fixez le rendez-vous (ex. Samedi à 21h00). L'événement sera automatiquement référencé dans le Calendrier de la Guilde. Laissez vide pour une sortie immédiate ou « dès que le groupe est plein ».
  • Classes recherchées : Indiquez si votre composition requiert des rôles spécifiques (ex. Pandawa pour le placement, Eniripsa pour le soin).
  • Message / Consignes : Précisez les prérequis (vocal Discord, connaissance de la stratégie, stuff prérequis). Le texte est garanti 100 % responsive et s'adapte à tous les écrans sans déborder.
  • Publication Discord : Cochez l'option pour publier automatiquement l'annonce dans le salon dédié et notifier un rôle de votre choix (ex. @Donjons).
Mode Multi-Donjons pour les séries de boss

Vous prévoyez une session complète de succès ou une série de donjons d'alignement ? Le mode Multi-Donjons vous permet de chaîner plusieurs donjons consécutifs sur la même sortie avec un ordre de passage précis.

2. Rejoindre et participer

Tout membre de la guilde peut s'inscrire en un clic :

  • Postuler : Cliquez sur Postuler sur la carte du site ou directement sur le bouton interactif du message Discord.
  • Sélection de la classe : Choisissez la classe de votre personnage joué. Votre avatar s'affichera instantanément dans l'équipe.
  • File d'attente automatique : Si la sortie est complète (ex. 4/4), vous êtes placé en File d'attente. Si un participant se désiste, le premier membre en file d'attente est automatiquement promu dans l'équipe principale !
  • Gestion par le meneur : Le créateur de la sortie dispose des boutons d'administration pour accepter un joueur en attente, modifier la date ou clôturer la sortie une fois terminée.
  • Se désinscrire : Un bouton Quitter permet de libérer sa place à tout moment de manière autonome.

3. Fiches tactiques et Guides intégrés

Chaque carte de donjon met à disposition des raccourcis directs vers les meilleures ressources communautaires :

  • Fiche SigilOS : Ouvrez la fiche interne du boss (points de vie, résistances élémentaires, état invulnérable, sorts et conseils tactiques).
  • Guide DPLN : Redirection directe vers le guide complet rédigé par DofusPourLesNoobs.
  • DofusDB : Accès instantané à l'encyclopédie DofusDB pour consulter les monstres de la zone, les seuils de drop et les succès associés.

4. Filtres intelligents & Ergonomie

Le module dispose d'une barre de filtres moderne et épurée pour retrouver rapidement les sorties qui vous intéressent :

  • Recherche instantanée : Tapez le nom d'un donjon, d'un boss, d'une quête ou le pseudo du meneur.
  • Filtres par Mode : Basculez d'un clic entre Tous, Donjons, Quêtes et Défis.
  • Statut de recrutement : Filtrez les sorties Ouvertes uniquement pour trouver immédiatement un groupe avec des places libres, ou cochez Mes sorties pour suivre vos inscriptions.
  • Paliers de niveau : Filtrez selon votre niveau de personnage : 1-50, 51-100, 101-150, 151-190, 190-200 ou 200 uniquement.
  • Filtre par classe : Trouvez les sorties qui recherchent spécifiquement votre classe.

5. Configuration pour les Officiers

Pour activer la publication automatique Discord, rendez-vous dans les paramètres d'administration de votre guilde :

  1. Accédez à Paramètres > Donjons & Quêtes.
  2. Sélectionnez le salon Discord textuel où les annonces doivent être postées.
  3. (Optionnel) Choisissez le rôle autorisé au ping pour mentionner les membres intéressés par les donjons.
  4. Vérifiez que le bot SigilOS possède les permissions Discord « Voir le salon », « Envoyer des messages » et « Intégrer des liens ».
Règles anti-spam et clôture automatique

Afin de préserver la lisibilité du tableau de bord et de vos salons Discord, un membre ne peut avoir que 3 sorties actives simultanées. Les sorties passées dont la date est dépassée sont automatiquement archivées après 48 heures.
